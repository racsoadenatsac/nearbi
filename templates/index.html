Verify it yourself

ledger.jsonlledger.jsonverify_ledger.py

Each line of ledger.jsonl is one event with its block, transaction, receipt and the exact EVENT_JSON log it came from. Lines are hash-chained: line_hash = sha256(canonical_json(line minus hashes) + prev_hash), starting from 64 zeros, so no past row can be changed or dropped without breaking every later hash. The verifier is standard-library Python:

curl -sO ${site}ledger.jsonl
curl -sO ${site}verify_ledger.py
python3 verify_ledger.py ledger.jsonl         # hash chain, split math, totals
python3 verify_ledger.py ledger.jsonl --rpc   # + re-fetch every event and block from NEAR RPC

Or ask the contract directly:

curl -s ${rpc} -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"query","params":{"request_type":"call_function","finality":"final","account_id":"${splitter_id}","method_name":"get_stats","args_base64":"e30="}}' \
  | python3 -c 'import sys,json; print(bytes(json.load(sys.stdin)["result"]["result"]).decode())'
